Nossa Trajetória

Hardware

Estudamos eletrônica, componentes, sensores, montagem de circuitos e integração de dispositivos. Esses conhecimentos permitiram construir a estrutura física do robô e conectar todos os sensores utilizados no projeto.

Redes

Aprendemos conceitos de comunicação entre dispositivos, protocolos de rede e transmissão de dados. Com isso, o robô consegue enviar as informações coletadas pelos sensores através da rede Wi-Fi para o sistema Aura Sync.

Programação

Desenvolvemos lógica de programação, algoritmos e aplicações de software. O robô foi programado em C, enquanto os sistemas Web e Desktop foram criados para processar, armazenar e exibir os dados coletados.

Projeto Final

O Aura Sync integra todas as Unidades Curriculares. O Hardware fornece a estrutura física e os sensores, as Redes realizam a transmissão dos dados via Wi-Fi e a Programação controla o robô e apresenta as informações nos sistemas Web e Desktop, formando uma solução completa de monitoramento inteligente.
